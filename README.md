# Projeto-Weatherview
🌦️ WeatherView
Uma aplicação web simples e intuitiva para consulta de previsão do tempo em tempo real para qualquer cidade do mundo.

🚀 Demonstração
Você pode acessar a aplicação online através do link:

https://weatherview.site.je/

✨ Funcionalidades
Busca Global: Pesquise a condição meteorológica de qualquer cidade.

Dados em Tempo Real:

Temperatura atual em °C.

Condições do clima com ícones dinâmicos.

Horário da última atualização dos dados.

Porcentagem de umidade do ar.

Velocidade do vento.

Interface Responsiva: Layout moderno e adaptável para dispositivos móveis e desktops.

🛠️ Tecnologias Utilizadas
Frontend: HTML5, CSS3, JavaScript (ES6+)

API: OpenWeatherMap API

🔧 Como rodar o projeto localmente
Clone o repositório:

Bash
git clone https://github.com/seu-usuario/weatherview.git
Acesse a pasta do projeto:

Bash
cd weatherview
Abra o projeto:

Basta abrir o arquivo index.html em seu navegador de preferência ou utilizar a extensão Live Server no VS Code.
